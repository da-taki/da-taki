## Research

### **Unequal Tongues** · `accepted`

**Journal of Science and Technology**

Studied emotional drift in multilingual language models across 1,800+ outputs.

The short version: translating a feeling is not the same as preserving one. This is inconvenient for multilingual AI systems and extremely convenient for writing a paper about them.

### **Access-Evolving Value Semantics** · `submitted`

**SN Computer Science**

A formal and empirical study of deterministic programs whose values evolve when accessed.

Built around **Hiesenoether**, an experimental programming language where observation is not free. The work includes **2.2M+ executions**, exhaustive permutation validation across **112 configurations with 0 mismatches**, scaling experiments reaching **R² = 0.999999**, and static analysis across **73 PyPI packages**.

Apparently “what if reading a variable made things worse?” was a research agenda.

### **λOpt** · `under review`

**Springer Machine Learning**

A formal ML systems safety paper on optimizer-state rewrite correctness, with **Lean 4 proofs** and checkpoint recovery experiments.

Current results include **0 false negatives across 11 checkpoint corruption scenarios** and a rewritten-state Lipschitz fix for Adam optimizer failures.

In other words: if an optimizer claims its rewritten state is safe, I would like it to prove it.

## Things I Built

### **CodeUp**

A blind-first, voice-driven Python IDE that treats non-visual interaction as the default, not an accommodation.

CodeUp includes English and Hindi voice navigation, code sonification, audio breakpoints, spoken error recovery, step-by-step trace narration, AST-based variable tracking, and sandboxed execution.

It was piloted with **10 visually impaired students** at the **School for the Blind and Deaf, Patiala**. Seven rated it **10/10**, and the remaining three rated it between **7.5 and 8.5**. The school has since adopted it, and I visit twice monthly to teach programming through it.

Following an introduction from **Dr. Homiyar Mobedji at Benetech India**, CodeUp was referred for independent technical evaluation by teams at **Vision-Aid** and the **Technical Training Institute of the Poona Blind Men’s Association**.

Which is a very formal way of saying that the project I started building at home is now being tested by people who actually know what they are doing.

### **CodeUp Web**

A voice-first website builder that lets students create, preview, audit, improve, and export websites through continuous conversation.

It supports interruptible narration, streamed responses, synchronized speech rendering, and mixed Hindi-English workflows.

Because after building one accessibility tool, the sensible decision was apparently to build its sibling too.

### **Hiesenoether**

An experimental programming language for studying access-evolving computation and deterministic semantic divergence.

In Hiesenoether, observing a value can alter what it becomes.

Yes, it runs.
No, you should not build your banking backend in it.
Yes, I checked.
